02Applied ML Research2025 — 2026

Oncology clinical decision support↗

The question was whether a small model, fine-tuned, could beat its own base and GPT-3.5 on structured clinical tasks. I fine-tuned Med42-8B on 14k synthetic NSCLC cases with QLoRA across six iterative training runs. Partway through, I found that 30% of one run's outputs were duplicates — I rewrote the data generator, regenerated the corpus, and the next run converged cleanly on data that couldn't be memorized. I also built evaluation beyond ROUGE alone, since ROUGE scored a wrong drug recommendation at 97.8.

0.705ROUGE-1 on held-out test data — 2.8× both base Med42 and GPT-3.5
71.4%clinically appropriate drug recommendations on the held-out drug-recall cases
3.80/4format adherence — the only model that holds structure across all three task types
30% → 0.25%duplicate response rate after regenerating the 14k-case corpus

Python · PyTorch · QLoRA · Hugging Face · Hex · SQL
